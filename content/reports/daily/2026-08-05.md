# 日报：2026-08-05

## 今日学习综述
今日正式进入 L2 阶段，开始 Vue Router 与前端路由核心原理的深度研究。基于已有知识 (SPA 路由 hash / history 模式) 进行系统化梳理，并建立研究框架。

## 关键发现与结论
1.  **SPA 路由核心机制**：前端路由的实现依赖于 `hashchange` 事件 (hash 模式) 或 `history.pushState` / `popstate` 事件 (history 模式)。Vue Router 本质上是对这两种浏览器 API 的封装，并解决了组件映射、路由守卫、懒加载等工程问题。
2.  **Vue Router 是 Vue 插件**：Vue Router 通过 `Vue.use(Router)` 安装，其核心逻辑是挂载 `$router` (路由实例) 和 `$route` (当前路由对象) 到 Vue 原型上，并利用 `<router-view>` 动态渲染匹配的组件。
3.  **核心概念**：`routes` 配置数组是路由表，定义了路径与组件映射；`router-link` 和 `router-view` 分别是声明式导航和渲染出口。

## 知识盲区识别
- **待确认**：Vue Router 4 (Vue3 版本) 的 `createRouter` 和 `createWebHistory` API 与 Vue2 的具体差异。
- **待确认**：路由守卫 (`beforeEach`, `beforeResolve`, `afterEach`) 的内部执行顺序和异步处理机制。
- **待确认**：嵌套路由场景下，`<router-view>` 的渲染层级和 `name` 属性的作用。
- **待确认**：动态路由匹配 (`/user/:id`) 与 `props` 的传递模式。

## 待办事项
1.  [ ] 阅读 Vue Router 官方文档，验证上述待确认点。
2.  [ ] 本地搭建一个简化的 Vue + Vue Router 项目，测试不同路由模式。
3.  [ ] 撰写一篇关于“前端路由原理”的笔记，总结 hash 与 history 模式的区别。
4.  [ ] 尝试实现一个简化版的路由系统，加深理解。
