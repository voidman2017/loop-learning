今日正式启动 Vue Router 与前端路由核心原理的研究。从项目初始化阶段（L1）进入 L2 学习阶段，重点关注路由系统的设计理念与实现机制。由于尚无历史学习记录，今日主要进行概念梳理与知识框架搭建。

## 关键发现与结论

1. **Vue Router 的核心抽象**：Vue Router 将 URL 与组件进行映射，核心是路由表（routes 数组）和路由器实例。路由匹配基于路径模式，支持动态路由参数、嵌套路由、命名路由等。（待确认：具体实现细节可能因版本而异，参考 Vue Router 4.x 文档）
2. **前端路由两种模式**：Hash 模式（利用 `hashchange` 事件）和 History 模式（利用 HTML5 History API `pushState`/`replaceState`）。History 模式需服务端支持，否则刷新会 404。（待确认：服务端配置要求）
3. **导航守卫体系**：Vue Router 提供全局守卫、路由独享守卫、组件内守卫，形成完整的导航控制流程。守卫通过 `next()` 函数决定导航是否继续。（待确认：钩子函数执行顺序）
4. **嵌套路由实现**：通过 `children` 配置实现多级路由，渲染时使用 `<router-view>` 嵌套，组件树与路由树对应。（待确认：性能优化策略）

- 大型项目中路由模块拆分的最佳实践
